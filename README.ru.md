# ScreenIt

**ScreenIt 0.2.0**

ScreenIt — локальная утилита для Windows, которая помогает быстро делать снимки экрана, добавлять к ним пометки и передавать результат в ИИ-ассистент, разработчику, дизайнеру или коллеге.

**Снимок → Указание → Комментарий → Продолжение → Вставка**

Выберите область экрана, отдельное окно или целый монитор и добавьте пометки прямо в overlay. Отдельного окна редактора нет. Маркеры **A1**, **A2** связывают точки на изображении с комментариями, которые остаются обычным редактируемым текстом. Следующие снимки B, C и далее добавляются в ту же сессию.

Перейдите в поле чата и нажмите **Ctrl+Alt+V один раз**. ScreenIt последовательно вставит каждый снимок отдельным изображением, а затем — структурированные комментарии.

## Возможности

- Windows 11 x64, работа из области уведомлений и глобальные горячие клавиши.
- Захват выбранной области, отдельного окна или целого монитора.
- Работа с несколькими мониторами и разным масштабом интерфейса.
- Маркеры с комментариями; перемещение, редактирование и удаление маркеров.
- Стрелки, рамки, отмена и повтор действий для текущего снимка.
- Сессии из нескольких снимков: A, B, C… Z, AA…
- Вставка всей сессии одной командой.
- Быстрая очистка сессии с подтверждением.
- Системная, светлая и тёмная темы, русский и английский интерфейс (0.2.0).
- Настраиваемые глобальные горячие клавиши.
- Компактные уведомления по размеру содержимого над панелью задач, с плавным появлением и исчезновением, включая подтверждение запуска ScreenIt в фоне; без звука.
- Локальная работа: без аккаунтов, облачного сервиса, серверной части и телеметрии.

## Установка

### Установщик

1. Скачайте **ScreenIt-Setup-0.2.0.exe** из раздела [Releases](https://github.com/nickkho0201/ScreenIt/releases).
2. Запустите установщик.
3. Откройте ScreenIt из меню «Пуск».
4. После запуска приложение работает в области уведомлений Windows.

Установка выполняется только для текущего пользователя, не требует обязательных прав администратора и не включает автозапуск. Удаление программы удаляет файлы приложения, но сохраняет пользовательские настройки.

**ScreenIt пока не имеет цифровой подписи. Windows SmartScreen может показывать предупреждение при запуске ранних версий из-за отсутствия сертификата подписи кода.** Полностью отключать SmartScreen не требуется.

### Переносная версия

Скачайте **ScreenIt-0.2.0-win-x64-portable.zip** из раздела [Releases](https://github.com/nickkho0201/ScreenIt/releases), распакуйте архив и запустите **ScreenIt.App.exe**.

### Требования

**Windows 11 x64.**

Оба варианта поставки автономны: отдельно устанавливать .NET Runtime не требуется.

Поддержка Windows 10 официально не заявляется.

## Быстрый старт

1. Нажмите **Ctrl+Alt+S**, выделите нужную область мышью и отпустите кнопку. Для захвата всего текущего монитора нажмите **Space**. Снимок сразу добавится в сессию.
2. Для разметки удерживайте **Ctrl** при отпускании мыши или нажатии Space. Щёлкните по нужному месту — появится маркер **A1**. Введите комментарий и нажмите **Enter**. При необходимости добавьте другие маркеры, стрелки или рамки.
3. В режиме разметки нажмите **Ctrl+Enter**, чтобы сохранить снимок в текущую сессию и закрыть overlay. Повторите для снимков B, C и далее.
4. Перейдите в поле чата и нажмите **Ctrl+Alt+V один раз**. ScreenIt вставит все изображения по порядку, а затем — редактируемый текст комментариев.
5. Нажмите **Ctrl+Alt+X**, чтобы очистить текущую сессию. После подтверждения нумерация начнётся заново с A/A1.

Для снимка окна нажмите **W** в режиме выбора, наведите курсор на доступное окно и щёлкните. Повторное W возвращает выделение области; Space по-прежнему снимает текущий монитор. Удерживайте настроенную клавишу разметки при клике, чтобы открыть Annotation. Windows.Graphics.Capture захватывает выбранный HWND целиком, включая обычный заголовок и рамку: перекрывающие окна и подсветка ScreenIt не попадают в снимок. Пиксели окна снимаются при клике, а не из начального frozen desktop. Большое окно или окно между мониторами вписывается в annotation overlay для редактирования; снимок сохраняет полное физическое разрешение.

Во время вставки всей сессии оставайтесь в том же окне. Если вы переключитесь в другое приложение или произойдёт ошибка, вставка остановится, а сама сессия ScreenIt сохранится. Уже вставленные данные автоматически не удаляются, поэтому повторная попытка может создать дубликаты.

В меню области уведомлений откройте **Настройки**: разделы **Основные**, **Клавиши** и **О программе**.

В «Основных» доступны оформление **Как в Windows / Тёмная / Светлая** и язык **Русский / English**. Изменения применяются сразу. Для новых пользователей выбираются системное оформление и язык Windows: русский либо английский. Ранее выбранная светлая или тёмная тема сохраняется. Системное оформление реагирует на смену темы приложений Windows.

В «Клавишах» нажмите на сочетание и введите новое: Ctrl, Alt, Shift или Win с буквой, цифрой, F1–F12, Backspace, Delete, Insert, Home, End, PageUp/PageDown, стрелкой или Space. Если сочетание занято, недопустимо или повторяет другую команду, прежние клавиши остаются рабочими. «Восстановить стандартные» возвращает весь набор; при конфликте прежний набор сохраняется. Клавиши разметки остаются неизменными.

В разделе **Дополнительно** доступны ручные команды копирования изображений и комментариев.

Во время записи сочетания Settings временно перехватывает ввод, включая комбинации с Win, и подавляет записываемый gesture до отпускания клавиш. Esc отменяет запись; переключение в другое окно или закрытие Settings также завершает её. Это не позволяет обходить недоступность сочетания при обычной работе.

Для Capture можно назначить **Win+Shift+S**: пока ScreenIt работает с этим сочетанием, оно временно заменяет Snipping Tool. Смена Capture или выход освобождает перехват, настройки Windows не изменяются. В «Клавишах» также выбирается **клавиша разметки: Ctrl / Shift / Alt**. Решение принимается по её физическому состоянию при отпускании мыши/Space, в том числе если она входила в capture hotkey. Подсказка и внешнее свечение accent-рамки показывают удержание; overlay visuals не попадают в снимок. При отключённых Windows client-area animations используется статичная подсветка. Старые settings получают Ctrl по умолчанию; выбранная клавиша сохраняется в том же локальном файле настроек.

Все остальные поддерживаемые сочетания используют обычную регистрацию hotkeys Windows, включая Win+Shift+S для Paste/Clear. Общего перехвата занятых системных клавиш нет. При отказе отображаются конкретная комбинация и причина; прежнее рабочее сочетание остаётся активным и сохранённым.

## Горячие клавиши

Первые три сочетания — настраиваемые глобальные клавиши по умолчанию. Остальные доступны в режиме разметки.

| Действие | Горячая клавиша |
|---|---|
| Сделать снимок | `Ctrl+Alt+S` |
| Вставить всю сессию | `Ctrl+Alt+V` |
| Очистить сессию | `Ctrl+Alt+X` |
| Маркер | `M` |
| Стрелка | `A` |
| Прямоугольник | `R` |
| Изменить комментарий | `E` |
| Удалить выбранный элемент | `Delete` |
| Отменить действие | `Ctrl+Z` |
| Повторить действие | `Ctrl+Y` |
| Сохранить снимок | `Ctrl+Enter` |

Во время редактирования комментария:

- **Enter** — сохранить;
- **Shift+Enter** — новая строка;
- **Esc** — отменить редактирование.

Перед сохранением снимка завершите или отмените редактирование текущего комментария.

Отмена и повтор действий внутри поля комментария работают с текстом. Нажатие **Esc** сначала отменяет текущее действие или редактирование. Если на снимке уже есть пометки, при попытке отменить весь снимок ScreenIt запросит подтверждение.

## Приватность

ScreenIt работает локально.

Снимки и комментарии остаются на вашем устройстве. У ScreenIt нет:

- серверной части;
- телеметрии;
- аналитики;
- аккаунтов;
- фоновых сетевых запросов;
- автоматической отправки данных.

Команда вставки сессии передаёт данные только в выбранное вами приложение через буфер обмена Windows и имитацию стандартной команды вставки. Дальнейшая обработка зависит уже от принимающего приложения. ScreenIt не контролирует его сетевое поведение и работу сторонних менеджеров буфера обмена.

Единственное сетевое действие — явно запрошенная проверка обновлений через GitHub и отдельная команда загрузки установщика. Снимки и комментарии туда не отправляются. При запуске приложение не проверяет обновления.

Сессии хранятся только в оперативной памяти.

Оформление, язык, глобальные сочетания и клавиша разметки сохраняются локально в файле настроек версии 2:

```text
%LOCALAPPDATA%/ScreenIt/settings.json
```

Для последовательной вставки ScreenIt создаёт временные PNG-файлы в:

```text
%TEMP%/ScreenIt/Clipboard-v1
```

Они сохраняются после вставки, очистки сессии и выхода из приложения, чтобы принимающие программы успели их прочитать. Временные наборы старше семи дней удаляются при следующем запуске ScreenIt.

## Обновления (0.2.0)

В разделе **Настройки → О программе** нажмите **Проверить обновления**. Предлагаются только более новые стабильные версии; переход на старую версию не предлагается.

Установленная копия может скачать установщик и `SHA256SUMS.txt` с GitHub по HTTPS. Перед запуском проверяется SHA-256 именно этого установщика. После проверки ScreenIt запрашивает подтверждение: приложение закроется, а текущая сессия в оперативной памяти будет потеряна. При ошибке запуска приложение и сессия сохраняются. Установщик пока не подписан и может вызвать предупреждение SmartScreen.

Переносная копия предлагает открыть страницу выпуска для самостоятельного обновления. Загрузки помещаются в отдельный закрытый каталог внутри `%TEMP%/ScreenIt/Updates`. При неудачной проверке этот набор удаляется; проверенный файл может остаться после отмены или установки. Обновление сохраняет путь установки, идентификатор приложения и пользовательские настройки.

Раздел «О программе» показывает реальный процент и объём скачивания, если сервер передаёт размер файла; иначе — скачанные байты и индикатор без процента. Проверка, подготовка и запуск установщика имеют отдельные статусы. Ошибка указывает этап и предлагает «Повторить». Закрытие Settings отменяет операцию; скрытие и повторный показ сохраняют progress. ScreenIt сообщает только запуск установщика и закрывается после подтверждения, без заявления о завершении установки.

## Совместимость

Вручную подтверждена последовательная вставка сессии в **ChatGPT Web**, а также работа на текущей конфигурации Windows 11 с двумя мониторами и масштабом 100%/125%, включая отрицательные координаты второго монитора.

Совместимость с другими приложениями может отличаться в зависимости от того, как они обрабатывают буфер обмена Windows и автоматическую вставку.

Ограничения Windows могут мешать вставке в приложения, запущенные с повышенными правами.

## Известные ограничения

Window mode исключает все окна процесса ScreenIt, скрытые/свёрнутые/cloaked окна, служебные tool/menu окна, taskbar и desktop infrastructure. Protected capture, exclusive fullscreen, необычные прозрачные поверхности и HDR могут быть недоступны или отображаться иначе. При ошибке можно выбрать другое окно; fallback на crop desktop отсутствует. Может кратко появиться системный индикатор захвата Windows. Отдельные диалоги выбираются отдельно; независимые popups не объединяются с выбранным HWND. Browser/Explorer/hardware-accelerated apps требуют ручной приёмки на текущем desktop.

- Только Windows.
- Сессии хранятся только в оперативной памяти и не восстанавливаются после завершения работы или сбоя.
- Уже сохранённые снимки нельзя повторно открыть для редактирования.
- Интерфейс доступен на русском и английском языках.
- Зарезервированные Windows сочетания и клавиши, занятые другим приложением, могут быть недоступны; исключение — scoped Capture Win+Shift+S. Физическое подавление Snipping Tool требует ручной проверки на целевом Windows desktop.
- Установщик и исполняемый файл пока не имеют цифровой подписи.
- Масштабы 150%/200%, портретная ориентация монитора, HDR, защищённый контент и некоторые системные переходы пока не прошли полную ручную проверку.

## Разработка

Для сборки требуются Windows и **.NET 10 SDK**.

```powershell
dotnet build ScreenIt.sln -c Release
.\verification\ScreenIt.Verification\bin\Release\net10.0-windows\ScreenIt.Verification.exe
.\verification\Smoke.ps1
```

Проверка запуска с нестандартными сочетаниями: `Smoke.ps1 -CustomBindings -ReportName custom-hotkeys-smoke.json`. Явная проверка GitHub доступна командой `ScreenIt.Verification.exe --check-updates`; обычный набор проверок использует тестовые источники обновлений и не обращается в сеть.

Перед запуском проверок закройте обычный экземпляр ScreenIt, поскольку текущая сессия хранится только в оперативной памяти.

Служебные результаты проверок сохраняются в игнорируемом каталоге `artifacts/`.

Автоматические проверки дополняют, но не заменяют ручное тестирование.

Для сборки установщика используется **Inno Setup 7.1.0**. Подробнее см. [инструкцию по сборке релиза](installer/README.md).

Каталог `spikes/` хранит историю технических экспериментов. Основное приложение от этих проектов не зависит.

Порядок снимков в сессии, инструменты разметки и последовательная вставка сохраняют существующие контракты.
